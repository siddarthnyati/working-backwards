Working Backwards that doesn't stop at the press release.

+Amazon's PR/FAQ decides whether to build. It ends there by design — and that handoff is where the method dies: the narrative gets admired, then someone opens a blank ticket and starts from zero.

+This runs all nine stages — press release, FAQs, demo, docs, telemetry, requirements, release plan, readiness — with an LLM judge gating each one. Every requirement cites the paragraph it came from, because a requirement that can't cite anything is a fairly precise definition of scope creep.

An open Claude Skill · MIT license

Prompt → artifact → judge → you. Repeat nine times.

1You prompt the stage

One stage at a time — never "do everything." The prompt names the stage, the rules, and ends with do not continue. Ready-made prompts for all nine ship in the skill.

2The agent writes the artifact

The skill produces that stage's document and writes it to disk. Every claim carries a provenance tag, and it never invents a figure — gaps stay visible as [NEEDS EVIDENCE].

3LLM as judge

A separate review pass scores the artifact against 8 fixed dimensions. Six get real verdicts — PASS / REVISE / BLOCK. Two (strategic fit, feasibility) only ever produce questions routed to a named human: the judge is barred from ruling on what it can't know.

4You gate

Accept, send back, or override. Overrides are logged with your written reasoning in DECISIONS.md — recorded, never argued. Only then does the next stage unlock.

That's the whole system. Below: a real run — the actual prompt, the artifact it produced, the judge's verdict, and the complete document, at every stage. Empty Workspace: 61% of new workspaces never gain a second member.

A fictional team-collaboration SaaS. Signups create a workspace, find it empty, never invite anyone, and churn — the invite screen is three clicks deep in settings and almost nobody finds it. Six blockers, before a single requirement existed.

The pipeline's payback moment. At Stage 2 — before requirements, before design — the hostile-question banks surfaced six things that reshape the plan. Each is a question with an owner, never a finding: the skill can't assess legal exposure, so it names the person who can, and it has no way to mark its own question resolved.

The quiet one is BLK-03: an ownership dispute blocking the two slices that need no lawyer. The skill can't resolve it — but it put a name and a date on the meeting, which is more than the last two onboarding projects had.

One honest word, carried all the way down.

The 5.4× retention gap between team and solo workspaces is a correlation. The whole initiative rests on it being causal — so that claim is tagged [ASSUMED] at intake, and the tag survives into the press release, becomes an experiment requirement, and ends up in the readiness doc's failure modes. Nothing along the way is allowed to round it up to a fact.
