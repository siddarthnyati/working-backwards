# External FAQ — Empty Workspace

```
EFAQ-01 · Scope · ANSWERED
Q: What changed, in one sentence?
A: Setup now starts with your team and a working first page — inviting is one step, always
   skippable, and the blank workspace is replaced by usable templates. Source: PR ¶1.
```

```
EFAQ-02 · Dark patterns · ANSWERED
Q: Is this going to nag me like a social app — gate my workspace until I hand over my
   address book?
A: No, and the rule is written into the requirements: the invite step is skippable in one
   click, never blocks access to anything, and never re-prompts on a schedule (REQ-DP5).
   A solo workspace is a valid outcome. Source: PR ¶1.
```

```
EFAQ-03 · Contact import · OPEN
Q: Can I import teammates from Google or Outlook contacts?
A: Designed but not shipping yet — importing an address book raises consent and data-
   retention questions we route to privacy counsel before building, not after.
   → BLK-01 · Status: OPEN. The invite composer takes typed addresses today.
```

```
EFAQ-04 · Templates · ANSWERED
Q: Do templates overwrite anything, and can I get the blank workspace back?
A: Templates create content, never replace it, and "start empty" is always the last card in
   the gallery. Source: PR ¶5 / 03-demo-spec.md F3.
```

```
EFAQ-05 · Incentives · OPEN
Q: Do I get anything for inviting my team?
A: Undecided. Whether invite incentives (free seats, discounts) help or just get gamed is a
   commercial question with real cannibalization risk.
   → BLK-05 · Ask: commercial lead
```

```
EFAQ-06 · Existing workspaces · ANSWERED
Q: I already have a workspace. Does any of this hit me?
A: You get the composer in the sidebar and the template gallery for new pages. Your
   first-run is long gone; we won't replay it at you. Source: PR ¶8.
```
